# HIPPOSTAT

## Analyse visuelle des courses hippiques

HIPPOSTAT est une application web permettant de visualiser rapidement l'historique des chevaux engagés dans une course.

L'objectif est de faciliter l'analyse grâce à des graphiques interactifs, sans remplacer l'expertise du turfiste.

## Fonctionnalités

- 📊 Historique graphique des chevaux
- 🐎 Sélection dynamique des partants
- 💰 Visualisation des gains estimés
- ℹ️ Infobulles détaillées
- 📅 Historique multi-années
